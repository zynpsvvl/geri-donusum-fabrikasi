# Geri Dönüşüm Fabrikası — Tiko ile Kodla

Code Week etkinliği için hazırlanmış, 3. ve 4. sınıf öğrencilerine yönelik etkileşimli bir algoritma ve kodlama oyunu.

**[Oyunu tarayıcıda aç](https://zynpsvvl.github.io/geri-donusum-fabrikasi/)**

![Geri Dönüşüm Fabrikası oyun kapağı](og-cover.png)

## Oyun

Öğrenciler, plastik, kâğıt, metal ve cam ürünleri karışık sırayla doğru geri dönüşüm bölümüne göndermek için Tiko'ya komutlar verir. Kod blokları bir program alanına yerleştirilir; program çalıştırıldığında her ürünün doğru kutuya gidişi animasyonla gösterilir. Seviyeler tamamlandıkça yeni zorluk aşamaları açılır.

Görevler sırayla şu becerileri çalıştırır:

1. **Başlangıç:** Dört karışık ürünü dört geri dönüşüm kutusuna ayır.
2. **Orta:** Aynı algoritmayı altı üründe, tekrarlanan malzemelerle çalıştır.
3. **İleri:** Sekiz ürünü ayır, yanlış cam yönlendirmesini program izinden bulup düzelt.

## Öğrenme hedefleri

- Algoritmik düşünme ve komutları doğru sıraya koyma
- Koşulları kullanarak karar verme
- Döngü ile tekrar eden işlemleri fark etme
- Programı izleyerek hatayı bulma ve düzeltme
- Geri dönüşüm malzemelerini doğru sınıflandırma
- Başarıyla tamamlanan seviyelerle giderek artan zorlukta çalışma

## Sınıfta kullanım

1. Öğrencilerle oyunun girişindeki görev akışını inceleyin.
2. Komut bloklarını çalıştırmadan önce ürünlerin gideceği kutuları tahmin etmelerini isteyin.
3. Programı çalıştırıp sonuçları tahminlerle karşılaştırın.
4. Hata ayıklama görevinde öğrencilerden yanlış koşulu ve düzeltme gerekçelerini açıklamalarını isteyin.

Oyun tek bilgisayarda bireysel veya küçük gruplarla kullanılabilir. İnternet erişimi gerektirmeyen çevrimdışı dosyası da repoda `index.html` olarak bulunur.

## Teknik bilgi

Oyun tek bir HTML dosyasında HTML, CSS ve JavaScript ile çalışır. Harici kütüphane, kurulum veya ağ isteği kullanmaz. Masaüstü ve mobil ekranlara uyumlu tasarlanmıştır; animasyon azaltma tercihini de dikkate alır.
